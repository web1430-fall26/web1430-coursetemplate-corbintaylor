# Rationale

The filter was the most challenging because the requirements for it were different from the previous filter we had created. This time, instead of wiping the div, I had to set the cards that did not meet the search requirement to be hidden. That ended up being a little difficult. I implemented keyboard accessibility for the tab component by creating a roving tabindex. It sets the selected tab's index to 0, while setting the unselected tabs to -1. It also included a keydown event listener to handle arrow, home, and end key inputs. Wrapping the index by using % tabs.length wasn't obvious in the beginning. I used event delegation in the accordion because it allowed me to set up one click handler instead of four. I would refactor the live filter to include other possible search parameters.
