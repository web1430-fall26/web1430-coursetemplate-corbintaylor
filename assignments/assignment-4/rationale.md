# Rationale 

I chose the Open Library API. It tells a story about books with a particular title. Users can clicked "Expand Details" to see the author and year if desired. My normalization function protects my rendering code by providing a default option in the event that an attribute is not present. This is done by using || and a default string. Without this, the data could be blank or there might be some other issue. An example error path is when the user presses the search button without typing anything in the search bar. An if statement within the handleSubmit function checks whether the title exists and displays an error asking for the title if it does not exist. If I were building this for a real audience, I would add an image of the book cover. That would require some other API request because the Open Library API does not appear to provide images of the covers.
