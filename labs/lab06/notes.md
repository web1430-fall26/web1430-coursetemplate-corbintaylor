# Process Reflection

Event delegation allows you to use one event listener that functions for all elements within a specified group. It simplifies the code, making it easier to manage and maintain. The attribute "aria-expanded" tells screen-readers that a collapsable element is either open or closed. By setting the display to none in JavaScript instead of using the hidden attribute with CSS, you would break the styles that rely on the hidden attribute. Instead of keeping all the styling in CSS, you would then have to remember display elements again within your code. Doing it within JavaScript would be disorganized. The accordian does not have the roving tabindex because the buttons are already in the natural tab order. The tabs use the roving tabindex because each tab is not separate from the others. It saves the selected tab, allowing users to tab back in to that tab as well as tab out immediately. By announcing that the tabs are in a tab-list also means that the tabs should use the roving tabindex to not confuse screen readers.
