# Process Reflection

Input events trigger every time there is a change to a field, whereas blur events trigger only when the element loses focus. Blur is more appropriate here because people need time to fill in an input field. Telling them that their input is wrong when they haven't finished is not helpful. The aria-describedby attribute is attached to the input fields in this lab and contains the ID of the corresponding error span. This is important because it allows people who use screen readers to know that an input field is connected to an error message. Without doing anything, the focus does not move when form errors occur. To not leave keyboard users hanging, the focus should be put on the first incorrect field, which is what this lab does by tracking the first error.
