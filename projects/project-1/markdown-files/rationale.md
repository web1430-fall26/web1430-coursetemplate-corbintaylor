# Rationale

I designed a website for an organization that sells electric bikes. I chose blue colors because they reminded me of electricity. As for the typography choices, I went with them because I wanted the page to feel clean and fast, similar to an e-bike. I decided that anything that was not the root or the reset was a component for simplicity. Many styles were reusable. The tabs were the hardest to implement accessibility because it involves a click event listener and a keydown event listener. You also need to carefully define the IDs, the aria-controls attributes, and the aria-labelledby attributes. I learned that taking time to make sure these attributes are all correct in the beginning saves time down the road. A developer would need to know that my CSS files are placed into a file named, "css". The base contains the root tokens and the reset, and the components file imports from the base file. In the HTML, only the components file needs to be linked.
